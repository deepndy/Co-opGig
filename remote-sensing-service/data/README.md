# Sample data

No real, copyrighted, private, or geospatial imagery is bundled. Tests generate tiny synthetic PNG images at runtime. For a manual smoke test, create two PNG/JPEG/WEBP images of the same dimensions and submit them as `imageT1` and `imageT2`.

The service does not download datasets. If you later use LEVIR-CD, WHU-CD, SpaceNet, or Inria Aerial Image Labeling, independently review the current dataset licence, access terms, intended use, imagery resolution, labels, and geographic suitability before downloading. No dataset suitability or licence clearance is asserted here.
